# AI System Workflows

This repo is where I build and test AI workflows.

I’m focused on multi-step systems that combine prompting, retrieval, and structured outputs to solve real tasks. Each project is an experiment in how to make these systems more reliable and easier to understand.

## What’s in here

- Prompt chaining and multi-step flows  
- Basic RAG setups  
- Structured outputs  
- Early agent patterns  

## How I approach this

Most workflows follow a simple pattern:
input → generate → retrieve (if needed) → refine output

I keep things lightweight and iterate based on what actually works.

## Next

Improving reliability, testing different structures, and building slightly more complex systems.
